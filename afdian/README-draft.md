# biaoge - 爱发电赞助页

## 关于 biaoge

biaoge 是一个中文优先的 Excel/CSV 命令行工具，20 个命令覆盖表格日常：SQL 直查、合并拆分、透视表、VLOOKUP 平替、数据体检、文件监控、终端出图……

纯本地离线，数据不出电脑。不会 pandas 也能 3 分钟上手。
